# Карточки постановки задач (для архитектора)

Заполните карточку своими словами — на русском или польском. Пустое поле лучше догадки: всё незаполненное агент-дирижёр соберёт в один список вопросов (не больше пяти) и задаст до начала работы. Из карточки он составит бриф с критериями приёмки; вы утверждаете бриф один раз.

Три правила, которые избавляют от доработок:
1. **Эталон вместо прилагательного.** Не «аккуратно оформить», а «как лист PB-A-03 проекта X».
2. **Что нельзя менять — писать явно.** Иначе менять можно всё.
3. **Что решаете только вы — писать явно.** Всё, что касается проектного решения и соответствия нормам, остаётся за вами.

## Карточка 1. Модель по исходным материалам (маршрут `intake`, затем `model`)

```
ЗАДАЧА: построить модель в Archicad по исходным материалам
ОБЪЕКТ: (название, что это за здание, сколько этажей)
ИСХОДНЫЕ ФАЙЛЫ:
  - (имя файла) — (что это: задание, план этажа, разрез, фасад, экспликация)
  - …
ЧТО МОДЕЛИРОВАТЬ: (стены, проёмы, перекрытия, крыша, лестницы, зоны; что НЕ моделировать)
СЛОИ: (план слоёв — файл или «как в шаблоне бюро …»)
ИЗВЕСТНЫЕ РАЗМЕРЫ ДЛЯ ПРОВЕРКИ МАСШТАБА: (например, «ось A–D = 18,40 м», «высота этажа 3,00 м»)
ПРОГРАММА ПОМЕЩЕНИЙ: (список помещений с минимальной площадью — если есть)
ДОПУСКИ: (длина ±… см, площадь ±… %; если не указано — 1 см и 2 %)
НЕ МЕНЯТЬ: (исходный файл проекта, шаблон, …)
РЕШАЮ Я: (толщины и составы стен, если их нет в материалах; любое расхождение между чертежами; …)
СРОК И БЮДЖЕТ: (когда нужно; сколько времени можно занять Archicad подряд)
```

Что вы получите: описание здания (`spec.json`) с указанием источника и уверенности по каждому элементу; **список вопросов** по всему, что прочитать не удалось; после ваших ответов — модель, в которой каждый элемент лежит на своём слое и сверен с описанием по количеству, размерам и площадям.

## Карточка 2. Комплект чертежей Projekt budowlany (маршрут `sheets-pb`)

```
ЗАДАЧА: сформировать комплект PB в PDF и DWG
МОДЕЛЬ: (файл Archicad)
ШАБЛОН ЛИСТОВ: (файл шаблона бюро; набор публикации, если есть)
СОСТАВ КОМПЛЕКТА: (перечень листов и документов — или «по sheets.pb.json, я проверю»)
  для каждого листа: номер, название, масштаб, формат
НУМЕРАЦИЯ ЛИСТОВ: (образец, например PAB-A-01)
ШТАМП: (значения полей: объект, адрес/działka, inwestor, projektant, nr uprawnień, стадия, дата)
ЭТАЛОН ОФОРМЛЕНИЯ: (лист или проект, на который должно быть похоже)
НЕ МЕНЯТЬ: (модель; уже выданные листы; …)
РЕШАЮ Я: (состав комплекта по действующему rozporządzeniu; масштабы; содержание описательной части)
СРОК И БЮДЖЕТ:
```

Что вы получите: макеты по шаблону, предпросмотр списка листов **до публикации**, затем PDF и DWG; проверку полноты, нумерации, масштабов, форматов и заполнения штампов по утверждённому вами перечню.

## Карточка 3. Доработка и комплект Projekt wykonawczy (маршрут `sheets-pw`)

```
ЗАДАЧА: доработать модель и чертежи PB, сформировать комплект PW
МОДЕЛЬ И КОМПЛЕКТ PB: (файлы)
ЧТО ДОРАБОТАТЬ В МОДЕЛИ: (детализация стен и перекрытий, столярка, отделка, …)
СОСТАВ КОМПЛЕКТА PW: (перечень листов — или «по sheets.pw.json, я проверю»; масштабы; детали; ведомости)
ОБЪЁМ ПО ДОГОВОРУ: (что заказчик требует в составе PW)
СВЯЗЬ С PB: (какой лист PW детализирует какой лист PB — или «определить и показать мне»)
НЕ МЕНЯТЬ: (решения, утверждённые в PB: габариты, отметки, планировки; выданные листы PB)
РЕШАЮ Я: (любое отступление от PB; узлы и детали; состав по договору)
СРОК И БЮДЖЕТ:
```

Что вы получите: то же, что для PB, плюс проверку, что каждый лист PW опирается на лист PB и ни один лист PB не потерян.

## Карточка 4. Сроки и риски (маршрут `estimate`)

```
ЗАДАЧА: оценить сроки выдачи документации и риск их срыва
НАЧАЛО РАБОТ:            СРОК ВЫДАЧИ:
РАБОЧИХ ЧАСОВ В ДЕНЬ НА ЭТОТ ПРОЕКТ:
ПАКЕТЫ РАБОТ (для каждого три оценки: лучшая / вероятная / худшая):
  - обработка исходных данных:      … / … / … часов, человек: …
  - модель:                          … / … / … часов
  - комплект PB:                     … / … / … часов
  - согласования (ожидание):         … / … / … рабочих дней
  - комплект PW:                     … / … / … часов
РИСКИ (вероятность и задержка лучшая / вероятная / худшая, в рабочих днях):
  - исходные материалы придут поздно или неполными:  … %,  … / … / …
  - заказчик изменит планировку после PB:            … %,  … / … / …
  - …
ДОПУСТИМЫЙ РИСК СРЫВА: (например, не больше 15 %)
ПРОШЛЫЕ ПРОЕКТЫ ДЛЯ КАЛИБРОВКИ: (план / факт в часах — хотя бы три)
```

Что вы получите: три даты готовности — с уверенностью 50, 80 и 95 %; вероятность срыва срока и уровень (зелёный до 15 %, жёлтый до 40 %, красный выше); запас в рабочих днях; какие пакеты чаще всего определяют срок; и меры по сокращению с выигрышем в рабочих днях для каждой.
