# Słownik badań FacetKit

| Termin | Definicja |
|---|---|
| Hipoteza (Hypothesis) | Falsyfikowalne twierdzenie dotyczące oczekiwanego zachowania lub wyniku działania agenta. |
| Pytanie badawcze (Research question) | Konkretne pytanie, na które ma odpowiedzieć eksperyment. |
| Facet | Nazwana instrukcja behawioralna lub mechanizm zdefiniowany w FacetKit. Zawsze podawaj dokładne ID, treść i wersję. |
| Karta zadania (Task card) | Powtarzalny scenariusz z Banku zadań społeczności. |
| Próba / uruchomienie (Trial / run) | Jedno wykonanie zadania w jednym określonym warunku. |
| Eksperyment | Zaplanowane porównanie obejmujące pytanie, warunki, kryteria, dowody i udokumentowane wyniki. |
| Baseline | Warunek odniesienia bez badanego Facetu lub mechanizmu. |
| Treatment | Warunek, w którym zastosowano badany Facet lub mechanizm. |
| Zmienna kontrolowana | Warunek utrzymywany bez zmian, aby porównanie można było zinterpretować. |
| Czynnik zakłócający (Confounder) | Czynnik inny niż badany mechanizm, który może wyjaśniać zaobserwowaną różnicę. |
| Rubryka (Rubric) | Wcześniej określone kryteria i kotwice ocen używane do oceny wyników. |
| Wstępna rejestracja (Pre-registration) | Zapisanie pytania, prognozy, warunków i kryteriów przed eksperymentem. |
| Obserwacja pilotażowa | Wczesna lub ograniczona próba służąca sprawdzeniu wykonalności zadania; nie stanowi formalnego potwierdzenia. |
| Replikacja | Niezależna próba odtworzenia wcześniej opublikowanego wyniku. |
| Pakiet dowodów (Evidence package) | Uporządkowany zestaw promptów, odpowiedzi, konfiguracji, logów, ocen i metadanych wspierających raport. |
| E0–E4 | Oznaczenia dojrzałości dowodów stosowane w FacetKit, opisane w [RESULTS.pl.md](RESULTS.pl.md). To konwencja projektu, nie uniwersalna skala naukowa. |
| E0 Proposed | Hipoteza została zapisana; brak kwalifikującej obserwacji. |
| E1 Observed | Zaobserwowano istotne zachowanie, ale bez kontrolowanego porównania. |
| E2 Tested | Hipotezę oceniono w udokumentowanym eksperymencie. |
| E3 Replicated | Wynik został niezależnie odtworzony. |
| E4 Cross-Project | Dowody oceniono w wielu projektach lub środowiskach. |
| SUPPORTED | Wyniki wspierają twierdzenie w udokumentowanych warunkach; nie jest to dowód uniwersalny. |
| NOT_SUPPORTED | Wyniki nie wspierają przewidywanego efektu w testowanych warunkach. |
| MIXED | Wyniki różnią się między próbami, kryteriami lub warunkami. |
| INCONCLUSIVE | Dowody nie wystarczają do rozróżnienia możliwych wyjaśnień. |
| NOT_REPLICATED | Niezależna próba nie odtworzyła wcześniej zgłoszonego wyniku. |
| N/A | Kryterium nie mogło zostać ocenione; nie oznacza zera. |
| Wynik negatywny | Rezultat, który nie wspiera prognozy lub ujawnia szkodliwy kompromis. |
