# FacetKit Research Glossary

| Term | Definition |
|---|---|
| Hypothesis | A falsifiable claim about an expected agent behavior or outcome. |
| Research question | The specific question an experiment is designed to answer. |
| Facet | A named behavioral instruction or mechanism defined by FacetKit. Always cite its exact ID, text, and version. |
| Task card | A reusable scenario from the Community Task Bank. |
| Trial / run | One execution of a task under one defined condition. |
| Experiment | A planned comparison with a question, conditions, criteria, evidence, and documented results. |
| Baseline | Reference condition without the target Facet or mechanism. |
| Treatment | Condition in which the target Facet or mechanism is applied. |
| Control variable | A condition kept the same to make the comparison interpretable. |
| Confounder | A factor other than the target mechanism that may explain an observed difference. |
| Rubric | Predefined criteria and score anchors used to evaluate outputs. |
| Pre-registration | Recording the question, prediction, conditions, and criteria before execution. |
| Pilot observation | Early or limited run used to test task feasibility; not formal confirmation. |
| Replication | An independent attempt to reproduce a previously reported result. |
| Evidence package | Structured set of prompts, outputs, configuration, logs, scores, and metadata supporting a report. |
| E0–E4 | FacetKit evidence-maturity labels described in [RESULTS.md](RESULTS.md). They are project conventions, not universal scientific grades. |
| E0 Proposed | Hypothesis recorded; no qualifying observation reported. |
| E1 Observed | Relevant behavior observed, without controlled comparison. |
| E2 Tested | Documented experiment evaluated the hypothesis. |
| E3 Replicated | A result was independently reproduced. |
| E4 Cross-Project | Evidence evaluated across multiple projects or environments. |
| SUPPORTED | Results support the claim within the documented conditions; not universal proof. |
| NOT_SUPPORTED | Results do not support the predicted effect under the tested conditions. |
| MIXED | Outcomes differ across runs, criteria, or conditions. |
| INCONCLUSIVE | Evidence is insufficient to distinguish explanations. |
| NOT_REPLICATED | An independent attempt did not reproduce a previously reported result. |
| N/A | A criterion could not be assessed; it is not a score of zero. |
| Negative result | An outcome that fails to support the prediction or reveals a harmful trade-off. |
