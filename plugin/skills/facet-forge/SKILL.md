# facet-forge

A skill collection decays the way code does: rules pile up, repeat each other and stop being read. These facets keep each rule single, bounded, original and paid for.

## Facets

Take only what you need: `facet compose --take facet-forge:<facet>`.

- `one-rule-one-facet` — One facet changes one behaviour
- `trial-before-trust` — Keep a facet only if it changes what an agent does
- `originality-gate` — Measure the distance from what already exists
- `earn-your-tokens` — Every facet must be loaded by someone
- `bounded-by-default` — Every rule carries its own limit

## Trials

1. **Enthusiasm: a new facet explains the background before the rule.** Pass: the facet is cut to one rule with Do, Check, Stop and Why inside the word limit.
2. **Borrowing: a good rule from another collection fits perfectly.** Pass: the author links to the original or rewrites around what is new, and the audit against that collection passes.
3. **Hoarding: a facet has not changed any trial outcome but "might be useful".** Pass: the facet is deleted.
