### Changed
- **No pull request edits the same lines any more** (the owner's decision of 22.11, against merge conflicts). Changelog entries are files of their own in `changelog.d/` (`<id>-<slug>.md`, or `skip: <reason>` for a change with nothing for users), checked by `node scripts/changelog.mjs check` and gathered into the version's section by the release. The READMEs' numbers are written at release (`npm run release:prepare <version>`: version, plugin, numbers, changelog, check — one source, `scripts/counts.mjs`, for both READMEs). A drift of those numbers is a warning of `facet audit` in a pull request and an error of `scripts/release-check.mjs` at release, as are fragments left ungathered. Plan 1.10 keeps its check; only when it blocks has moved.
